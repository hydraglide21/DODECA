## Distinction des niveaux de vérification

- **Rapporté** : résultat présent dans une sauvegarde ou un journal transmis.
- **Certifié** : résultat accompagné d'une pièce mathématique exacte vérifiable.
- **Contrôlé statiquement** : structure du code examinée sans exécution.
- **Exécuté** : script effectivement lancé et résultat observé.
- **Reproduit indépendamment** : résultat reconstruit par une procédure indépendante.

La présence d'un script dans le dépôt ne suffit pas à établir son exécution ou la validité mathématique de son résultat.
